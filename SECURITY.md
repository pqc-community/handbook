# Security policy

The PQC Handbook is a static website. This policy covers the site at [pqchandbook.com](https://pqchandbook.com) and the source in this repository.

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/pqc-community/handbook/security/advisories/new) rather than in a public issue. Include the affected page or file, what you found, and how to reproduce it.

We will acknowledge your report, keep you informed while we look into it, and credit you when the fix is published unless you would rather not be named.

## Errors in the guidance

If a page gives guidance that is wrong or out of date, for example a superseded algorithm or a misstated authority date, please open a public [issue](https://github.com/pqc-community/handbook/issues) with a link to the primary source, so that other readers can see the correction.
