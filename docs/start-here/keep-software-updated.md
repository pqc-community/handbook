The [UK NCSC timelines](https://www.ncsc.gov.uk/guidance/pqc-migration-timelines), modified 3 August 2026, say that for organisations using mainly commodity IT, migration should happen as vendors update browsers, operating systems, and mobile devices.

The [PQC Migration Handbook](https://english.aivd.nl/site/binaries/site-content/collections/documents/2024/12/3/the-pqc-migration-handbook/The+PQC+Migration+Handbook+.pdf) (AIVD, CWI, and TNO, December 2024) says regular adopters do not need to react to the quantum threat yet, and that an organisation on the boundary between urgent and regular should follow Section 3.2, which gives further guidelines on when to start migrating particular assets.

Handbook guidance: if you hold long-lived sensitive data or you ship a product that cannot update its signature check, you are on [I own the plan](./own-the-plan.md), not on this page.
