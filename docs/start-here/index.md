The five seats are paths into the same pages. Each one names the decisions for that seat, the reading order, and what you leave with.

- [I own the plan](./own-the-plan.md)
- [I own the product dates](./own-the-product-dates.md)
- [I have to ask a vendor](./ask-a-vendor.md)
- [I have to show evidence](./show-evidence.md)
- [I have to change a protocol](./change-a-protocol.md)

[Keep software updated](./keep-software-updated.md) is the page for a regular adopter, not a homepage card. The [PQC Migration Handbook](https://english.aivd.nl/site/binaries/site-content/collections/documents/2024/12/3/the-pqc-migration-handbook/The+PQC+Migration+Handbook+.pdf) (AIVD, CWI, and TNO, December 2024) says regular adopters do not need to react yet. Use that page when your software will pick up the change in an update. If you are not sure, the seat pages above still apply.

The shared operating layer starts at [Where to start](../migration-practices/where-to-start.md).
