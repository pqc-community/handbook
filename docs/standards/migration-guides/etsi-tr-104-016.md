## What it covers

ETSI TR 104 016 sets out a repeatable framework for quantum-safe migration in 11 steps, running from identifying the enterprise architecture to preparing for the next iteration. The final step makes the framework a repeatable migration cycle rather than a one-off project.

The report was produced by ETSI's Technical Committee on Cybersecurity (TC CYBER) and published as V1.1.1 on 25 October 2024. ETSI Technical Reports are informative documents rather than normative specifications, so the report recommends rather than requires.

## Relationship with other standards

The earlier [ETSI TR 103 619](/standards/migration-guides/etsi-tr-103-619/) (July 2020) describes a three-stage migration; this report frames the work as a cycle, which suits the expectation that algorithms and parameters will change again. See [Keep the ability to change again](/programme/changing-algorithms-again/) and [Crypto-agility](/learn/crypto-agility/).

It is a process framework and does not choose algorithms or set deadlines. Pair it with the handbook's [programme](/programme/), including its [Review and report](/programme/subsequent-review/) practice.
