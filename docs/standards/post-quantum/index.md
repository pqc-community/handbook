These publications specify NIST-approved quantum-resistant public-key algorithms, KEM combiner guidance, and status reports from the NIST post-quantum cryptography standardisation process.

### Key establishment and KEMs

| Publication | Summary | Reference |
| --- | --- | --- |
| FIPS 203 | Module-Lattice-Based Key-Encapsulation Mechanism Standard (ML-KEM). | [FIPS 203](/standards/post-quantum/fips-203/) |
| NIST SP 800-227 | Recommendations for key-encapsulation mechanisms, including hybrid key combiners. | [NIST SP 800-227](/standards/post-quantum/sp-800-227/) |

| Publication | Summary | Reference |

| NIST SP 800-208 | Stateful hash-based signature schemes (LMS, HSS, XMSS, and XMSSMT). | [NIST SP 800-208](/standards/post-quantum/sp-800-208/) |
