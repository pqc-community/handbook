## What it covers

NIST SP 800-208 specifies two families of stateful hash-based signature schemes — the Leighton-Micali Signature (LMS) system with its Hierarchical Signature System (HSS) multi-tree variant, and the eXtended Merkle Signature Scheme (XMSS) with its multi-tree variant (XMSSMT). Each private key contains a finite pool of one-time signing keys whose state has to be updated and never reused across signatures.

## Role in the post-quantum transition

[NIST IR 8547](https://doi.org/10.6028/NIST.IR.8547), October 2026, includes SP 800-208 among approved quantum-resistant digital signature options for tightly controlled environments such as firmware and code signing, where strict state tracking can be enforced in hardware modules. Where state cannot be managed safely, stateless schemes in [FIPS 204](/standards/post-quantum/fips-204/) and [FIPS 205](/standards/post-quantum/fips-205/) apply instead.
