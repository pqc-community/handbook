These publications set out how NIST manages transitions across cryptographic algorithm generations, security strengths, and key lifecycles.

| Publication | Summary | Reference |
| --- | --- | --- |
| NIST IR 8547 | NIST's report guiding the transition from quantum-vulnerable public-key standards to post-quantum cryptography. | [NIST IR 8547](/standards/transition-and-key-management/nist-ir-8547/) |
| NIST SP 800-131A | Rules for transitioning the use of cryptographic algorithms and key lengths (Rev. 2 final, with Rev. 3 draft noted). | [NIST SP 800-131A](/standards/transition-and-key-management/sp-800-131a/) |
| NIST SP 800-57 Part 1 | General recommendations for cryptographic key management and comparable security strengths. | [NIST SP 800-57 Part 1](/standards/transition-and-key-management/sp-800-57-part-1/) |
