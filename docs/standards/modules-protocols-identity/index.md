These publications govern how approved cryptographic algorithms are validated inside hardware and software modules and applied in network security protocols and PKI-based identity credentials.

| Publication | Summary | Reference |
| --- | --- | --- |
| FIPS 140-3 | Security requirements for cryptographic modules validated under the CMVP. | [FIPS 140-3](/standards/modules-protocols-identity/fips-140-3/) |
| NIST SP 800-52 | Guidelines for the selection, configuration, and use of TLS implementations. | [NIST SP 800-52](/standards/modules-protocols-identity/sp-800-52/) |
| FIPS 201-3 | Personal Identity Verification (PIV) of federal employees and contractors. | [FIPS 201-3](/standards/modules-protocols-identity/fips-201-3/) |
