# SEO Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Google one URL for each search this handbook can win, by changing five visitor-facing strings and nothing else.

**Architecture:** Four existing files change. A doc `title` is both the visible heading and the search-result title. Docusaurus appends ` | PQC Handbook`. A doc `description` is the search snippet. The homepage `Layout` title is the search-result title only; the hero heading stays the site title. No new module, no new test, and no sitemap edit. The existing Docusaurus build emits the titles and snippets.

**Tech Stack:** Docusaurus 3.10.1, React 19, TypeScript, Node 20. No new dependencies.

**Spec:** `planning/superpowers/specs/2026-11-09-seo-pass-design.md`

## Global Constraints

- These titles stay: `Where to start a post-quantum migration`, `Questions to ask a vendor`, `Post-quantum migration dates`, `Post-quantum product release dates`, `The vendor's migration plan`.
- `/migration-practices/vendor-plan/` still opens with `Decide what to ask the organisation that owns the stack, and how to keep the answer.`
